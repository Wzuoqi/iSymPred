## ✅ 完成的工作

### 1. 文件名变更
- **旧**: `output_potential_symbionts.tsv`
- **新**: `output_match_records.tsv`

### 2. 限制记录数量
- 每个共生菌只保留 Score 最高的 **5 条记录**
- 测试数据: ~2000 条 → 223 条 (减少 90%)
- 保留 55 个独特共生菌的最重要匹配

### 3. 重新计算评分（Adjusted_Score）
**新公式**:
```
Adjusted_Score = Base_Score × (Host_Match_Weight^2) × (Evidence_Weight^1.5)
```

**改进**:
- 宿主匹配平方：放大宿主特异性的影响
- 证据等级 1.5 次方：强化高质量证据的作用
- Mismatch 惩罚：0.5² = 0.25 (严重惩罚 -75%)
- Species 匹配奖励：1.5² = 2.25 (大幅提升 +125%)

### 4. 新增 Quality_Score
**公式**:
```
Quality_Score = (Host_Match × 40) + (Evidence × 30) + (Match_Level × 20) + (RA% × 10)
```

**用途**:
- 独立于丰度的质量评估
- 次要排序标准
- 质量筛选阈值

## 💡 使用建议

### 筛选高质量匹配
```python
high_quality = df[
    (df['Adjusted_Score'] > 50) &
    (df['Quality_Score'] > 80)
]
```

### 识别核心共生菌
```python
core = df.groupby('Symbiont_Taxon')['Adjusted_Score'].max().sort_values(ascending=False)
```

### 宿主特异性分析
```python
host_specific = df[
    df['Host_Match_Level'].isin(['Species', 'Genus', 'Family'])
]
```
