# iSymPred v2.2 更新总结

**日期:** 2026-01-08
**版本:** v2.2
**主要更新:** 宿主分类查询迁移到 ete3

---

## 🎯 核心改进

### 使用 ete3 替代本地 SQLite 数据库

**问题:** 本地 `insect_taxonomy.db` 文件超过 50MB，导致软件分发困难

**解决方案:** 使用 `ete3` 包的 `NCBITaxa` 进行在线查询

---

## ✨ 主要优势

### 1. 软件包更小
- ❌ **旧方案:** 需要打包 50MB+ 的 SQLite 数据库
- ✅ **新方案:** 无需本地数据库，软件包减小 50MB+

### 2. 数据更新
- ❌ **旧方案:** 需要手动更新本地数据库
- ✅ **新方案:** 可随时更新到最新的 NCBI Taxonomy

### 3. 覆盖范围
- ❌ **旧方案:** 仅包含预先收集的昆虫物种
- ✅ **新方案:** 覆盖 NCBI Taxonomy 全部物种

### 4. 维护成本
- ❌ **旧方案:** 需要维护本地数据库
- ✅ **新方案:** 无需维护，自动同步 NCBI

## 📝 使用变化

### 安装依赖

```bash
# 新增依赖
pip install ete3
```

### 命令行使用

```bash
# 旧方式（仍然兼容，但 --host-db 会被忽略）
python isympred/predictors/record_predictor.py \
    -i input.tsv \
    -d record_db.tsv \
    -o output.tsv \
    --host "Apis mellifera" \
    --host-db insect_taxonomy.db  # 此参数已废弃

# 新方式（推荐）
python isympred/predictors/record_predictor.py \
    -i input.tsv \
    -d record_db.tsv \
    -o output.tsv \
    --host "Apis mellifera"  # 不再需要 --host-db
```

### 首次运行

首次使用时会自动下载 NCBI Taxonomy 数据库（约 200MB）：

```
[Info] Using ete3 NCBITaxa for host taxonomy queries
Downloading taxdump.tar.gz from NCBI FTP...
Extracting taxonomy database...
[Host Taxonomy] Apis mellifera -> Order: Hymenoptera, Family: Apidae, Genus: Apis
```

数据存储位置：`~/.etetoolkit/taxa.sqlite`

### 代码变更

**文件:** `isympred/predictors/record_predictor.py`

## ⚠️ 注意事项

### 首次使用

- 需要下载约 200MB 的 NCBI Taxonomy 数据
- 需要网络连接
- 数据存储在用户目录（`~/.etetoolkit/`）

### 网络依赖

- 首次查询新物种时需要网络连接
- 后续查询使用本地缓存
- 可以离线使用已查询过的物种

### 性能

- 首次查询：~50ms（需要网络）
- 后续查询：~10ms（使用缓存）
- 与旧方案性能相当
