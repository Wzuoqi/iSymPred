## ✅ Task 2: Taxonomic Distance Feature

### Problem
Need to quantify the evolutionary distance between query host and database hosts using linear numerical values.

### Solution
Implemented `_calculate_taxonomic_distance()` method that calculates distance based on Lowest Common Ancestor (LCA).

### Distance Scale Definition

```
0   - Same species (同种)
1   - Same genus, different species (同属不同种)
2   - Same family, different genus (同科不同属)
3   - Same order, different family (同目不同科)
4   - Same class, different order (同纲不同目)
5   - Same phylum, different class (同门不同纲)
6   - Different phylum (不同门)
999 - Cannot calculate (无法计算)
```

### Implementation Details

**File Modified:** `isympred/predictors/record_predictor.py`

**Key Changes:**
1. Added `_calculate_taxonomic_distance()` method (lines 129-223)
2. Updated feature matrix generation to include taxonomic distance (lines 830-859)
3. Updated feature count from 9 to 10 features (v4.1 → v4.2)
4. Added output documentation for new feature (lines 884-896)

**Algorithm:**
```python
def _calculate_taxonomic_distance(self, db_host):
    # 1. Query taxid for both user host and database host
    # 2. Get lineage for both species
    # 3. Find common ancestors (LCA)
    # 4. Iterate through standard ranks to find lowest common standard rank
    # 5. Map rank to distance value (0-6)
    # 6. Return 999 if calculation fails
```

**Key Improvement:**
The algorithm was improved to handle non-standard taxonomic ranks (like "clade", "no rank") by iterating through standard ranks to find the lowest common standard rank, rather than using `max(common_ancestors)` which could return non-standard ranks.
