## 🗄️ Archive Policy

### Retention Period
- **Minimum:** 2 major versions back
- **Maximum:** 2 years (unless historically significant)

### When to Archive
- New major version released (e.g., v3.x → v4.x)
- Design documents after implementation complete
- Deprecated features removed from codebase

### When to Delete
- Documents older than 2 years (unless historically significant)
- Duplicate or redundant documentation
- Incomplete or draft documents that were never finalized
